# Screensaver

The screensaver on my LG monitor (29WK500/50S) is 2560x1080p. I use it oriented vertically,
so the effective horizontal orientation is 1080p. I also have the scale set to 1.25x due to
my main Dell monitor.

So horizontally, the LG monitor has effectively 1080 / 1.25 = 864 effective pixels. This causes
the 81-column wide artwork to get clipped on the sides to the point where I could only the 5 inner
letters, "MARCH".

There doesn't seem to be a clean way to get around this without some bespoke code, and I
don't want to maintain that, even with AI.

Hence, the new screensaver ASCII artwork. Obtained from this [website](https://patorjk.com/software/taag/) with the
"Delta Corps Priest 1" ASCII font. That's the font that's used for the Omarchy artwork as well.
