# Productivity

General workflows and skills for thinking, handoffs, learning, and skill authoring.

## Slash Workflows

- **[grill-me](../../commands/grill-me.md)** - Relentlessly sharpen a plan or design through an interview.
- **[handoff](../../commands/handoff.md)** - Capture the current conversation in a redacted handoff document so a fresh agent can continue the work.
- **[teach](../../commands/teach.md)** - Teach a skill or concept over multiple sessions using the current directory as a stateful learning workspace.
- **[writing-great-skills](../../commands/writing-great-skills.md)** - Manually load `writing-for-agents` to write or edit a skill.
- **[wait-what](../../commands/wait-what.md)** - Re-pitch the previous message with enough context and plain language.

## Loadable Skills

- **[grilling](grilling/SKILL.md)** - Interview the user through breadth-first design-tree rounds to stress-test a plan, decision, or idea before acting.
- **[writing-for-agents](writing-for-agents/SKILL.md)** - Write documents for agents, including skills, `AGENTS.md`, and referenced guidance.
